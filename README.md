# Bread log

My weekly gluten-free seeded loaves, with the macros for each batch and a short note on how healthy it is.

Live: https://reservetempo.github.io/bread-recipes/

Add a batch by putting a new entry at the top of `BATCHES` in `recipes.js`. New ingredients go in `FOODS` (nutrition per 100 g).

Run locally: `python -m http.server 8000`, then open http://localhost:8000/
